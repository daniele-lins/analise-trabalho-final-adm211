# Sobre o projeto
Este é um projeto de análise exploratória dos dados de amostragem que compõe o trabalho final da disciplina de Métodos Quantitativos Aplicados à Administração (ADM211) da UFBA.

# Sobre a amostra
Para a amostra foram sorteados 100 de uma população de 786 municípios dos 3 estados mais populosos do Nordeste do Brasil (Bahia, Pernambuco e Ceará), disponível no site [Sorteador](https://sorteador.com.br/resultado/994f545483b7).

Os dados amostrais foram coletados de duas fontes diferentes.
- "Distância da capital regional (nível de hierarquia 5) ou metrópole (nível de hierarquia 3)  mais próxima (km)": calculado por um script segundo os critérios registrados no repositório [calculadora_distancia](https://github.com/daniele-lins/calculadora-distancia/).
- "ÁREA km²", "Emissões de CO₂e por Habitante" e "Focos de Calor": retirados da base de dados do [IPS Brasil](https://ipsbrasil.org.br/explore/data?sort_order=asc&sort_by=municipality_name&page=1&states=29&states=26&states=23) filtrados apenas o ano de 2025 e os estados "BA", "PE" e "CE".
